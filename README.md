# What Should I

A "what should I watch / read / eat" random picker. Maintain a personal list of items
and spin the wheel to let the app decide for you.

- No backend — everything lives in `localStorage`
- Add, edit, delete, and mark items as done
- An animated spin/reveal (Framer Motion) picks a random item from your list
